# קונקטור וואטסאפ (WhatsApp MCP Connector)

שרת MCP (Model Context Protocol) שנותן ל-Claude גישה לוואטסאפ: קריאת הודעות, שליחת הודעות, תזמון הודעות לעתיד ועוד. מבוסס על [Baileys](https://github.com/WhiskeySockets/Baileys) — ספרייה לא-רשמית שמתחברת לוואטסאפ בדיוק כמו וואטסאפ Web, דרך סריקת קוד QR מהטלפון. אין צורך בחשבון WhatsApp Business API רשמי.

> ⚠️ **הערה חשובה**: זו ספרייה לא-רשמית שמדמה לקוח WhatsApp Web. שימוש בה סוטה מתנאי השימוש הרשמיים של וואטסאפ/Meta, וקיים סיכון (נמוך בשימוש סביר, אך קיים) לחסימה זמנית או קבועה של המספר. מומלץ להשתמש במספר משני ולא במספר הראשי שלכם, ולהימנע משליחת הודעות בנפח גבוה או לאנשים שלא הסכימו לקבל ממכם הודעות.

## מה זה נותן ל-Claude

| כלי (tool) | מה הוא עושה |
|---|---|
| `get_status` | בודק אם מחובר / ממתין לסריקת QR / מנותק |
| `get_login_qr` | מחזיר קוד QR (base64) לסריקה — להתחברות הראשונית |
| `request_pairing_code` | מחזיר קוד צימוד בן 8 תווים במקום QR — להתחברות ראשונית כשאין מכשיר שני לסרוק איתו |
| `list_chats` | רשימת שיחות אחרונות (אישיות וקבוצתיות) |
| `read_messages` | הודעות אחרונות משיחה מסוימת |
| `search_messages` | חיפוש טקסט חופשי בכל ההודעות שנצפו |
| `mark_chat_read` | סימון שיחה כנקראה |
| `send_message` | שליחת הודעת טקסט מיידית |
| `check_number_on_whatsapp` | בדיקה אם מספר טלפון רשום בוואטסאפ |
| `schedule_message` | תזמון הודעה לשליחה במועד עתידי |
| `list_scheduled_messages` | רשימת הודעות מתוזמנות (ממתינות/היסטוריה) |
| `cancel_scheduled_message` | ביטול הודעה מתוזמנת |

הקונקטור שומר "זיכרון" מקומי (בתיקיית `data/`, לא מסונכרן ל-git) של שיחות והודעות שהוא ראה מאז שהופעל — אין לו גישה להיסטוריה הישנה של הטלפון, רק להודעות שעברו דרכו מרגע ההתחברות. הודעות מתוזמנות כן נשמרות בין הפעלות, כך שאם הקונקטור יופעל מחדש לפני המועד — הן עדיין יישלחו כשהוא יעלה שוב.

## התקנה

```bash
cd whatsapp-connector
npm install
```

### התקנה על טלפון אנדרואיד (Termux)

אין צורך במחשב — אפשר להריץ את כל זה על אנדרואיד עם [Termux](https://f-droid.org/en/packages/com.termux/) (מומלץ להתקין מ-F-Droid, לא מ-Google Play — הגרסה שם לא מתעדכנת). שימו לב: זה עדיין "המכשיר" שמריץ את הקונקטור — וואטסאפ עצמו ממשיך לרוץ באפליקציה הרגילה בטלפון כרגיל, בלי קשר.

```bash
pkg update && pkg upgrade
pkg install nodejs git
git clone https://github.com/netanelh-ops/Overshav.git
cd Overshav/whatsapp-connector
npm install
```

כדי שהתהליך לא יופסק כשהמסך כבה (אנדרואיד "הורג" תהליכים ברקע כדי לחסוך סוללה):

```bash
termux-wake-lock          # מונע מאנדרואיד להרדים את Termux
npm start &                # מריץ ברקע
disown                     # כדי שהתהליך ימשיך גם אם סוגרים את הטרמינל
```

אפשר גם להתקין את החבילה `termux-services` כדי שהקונקטור יעלה אוטומטית מחדש אם הטלפון מתאתחל.

## התחברות ראשונית

לפני שימוש ראשון יש לקשר את החשבון. יש שתי דרכים — תלוי אם יש לכם מכשיר שני לסרוק איתו:

**אם יש מכשיר שני** (מחשב שהקונקטור רץ עליו, וטלפון שוואטסאפ מותקן בו):

```bash
npm run login
```

יופיע קוד QR בטרמינל. בטלפון: **וואטסאפ > הגדרות > מכשירים מקושרים > קישור מכשיר**, וסורקים.

**אם הקונקטור רץ על אותו הטלפון שוואטסאפ מותקן בו** (למשל דרך Termux באנדרואיד) — אי אפשר לסרוק QR שמוצג על אותו מסך עם המצלמה של אותו מכשיר, אז משתמשים בקוד צימוד במקום:

```bash
npm run login -- 972501234567   # המספר שלכם, עם קידומת מדינה, בלי +
```

יודפס קוד בן 8 תווים. בטלפון: **וואטסאפ > הגדרות > מכשירים מקושרים > קישור מכשיר > קישור עם מספר טלפון במקום**, ומזינים את הקוד (בתוקף לזמן קצר בלבד — אם הוא פג, מריצים את הפקודה שוב לקוד חדש). ניתן גם לבקש קוד צימוד דרך Claude, עם הכלי `request_pairing_code`, אם השרת כבר רץ.

בשתי הדרכים: עם ההתחברות הראשונה התהליך ייסגר אוטומטית ופרטי ההתחברות יישמרו בתיקיית `data/auth/` (מוחרגת מ-git — אל תשתפו אותה, היא שקולה לגישה מלאה לחשבון הוואטסאפ שלכם).

אם מתישהו מתנתקים מהטלפון (unlink), פשוט מוחקים את `data/auth/` ומתחברים מחדש.

## הרצה כשרת MCP (מומלץ — לחיבור ל-Claude)

```bash
npm start
```

זה מפעיל את שרת ה-MCP על stdio. אם `data/auth/` כבר קיים מהתחברות קודמת, החיבור יעלה אוטומטית בלי צורך בסריקה נוספת. אם עוד לא התחברתם, ניתן גם לקרוא לכלי `get_login_qr` דרך Claude כדי לקבל את קוד ה-QR ולסרוק אותו.

### הוספה ל-Claude Code

בקובץ ההגדרות של Claude Code (למשל `.mcp.json` בפרויקט, או `claude mcp add`):

```json
{
  "mcpServers": {
    "whatsapp": {
      "command": "node",
      "args": ["/נתיב/מלא/ל/whatsapp-connector/src/index.js"]
    }
  }
}
```

או דרך שורת הפקודה:

```bash
claude mcp add whatsapp -- node /נתיב/מלא/ל/whatsapp-connector/src/index.js
```

### הוספה ל-Claude Desktop

בקובץ `claude_desktop_config.json`, תחת `mcpServers`, אותו מבנה כמו למעלה.

### הערה למי שמריץ הכל מ-Termux (בלי מחשב)

חשוב להבדיל בין שני דברים שקורים כאן:

1. **שליחת הודעות מתוזמנות** — עובד לגמרי לבד, ברקע, כל עוד `npm start` רץ ב-Termux. אין צורך ש-Claude "יהיה מחובר" באותו רגע — התזמון כבר נשמר מראש והקונקטור בודק ושולח בזמן.
2. **שיחה עם Claude שמפעילה את הכלים בזמן אמת** (למשל "תשלח הודעה ל-X", "תראה לי מה כתבו לי") — לזה צריך ש-Claude עצמו ידבר עם השרת הזה, וזה קורה רק אם מריצים גם את **Claude Code** (`npm install -g @anthropic-ai/claude-code`) בתוך אותה סביבת Termux, ופותחים שיחה משם. שימוש רגיל באפליקציית Claude או באתר לא מגיע לשרת שרץ בטלפון שלכם — הוא רק "מקומי".

## פורמטים

- **מספר טלפון / JID**: אפשר להעביר לכלים מספר טלפון מלא עם קידומת מדינה וללא `+` (למשל `972501234567`), או JID מלא (`972501234567@s.whatsapp.net` לשיחה אישית, `xxxxx@g.us` לקבוצה).
- **`sendAt` בכלי `schedule_message`**: תאריך-שעה בפורמט ISO 8601, כולל אזור זמן, למשל `2026-08-24T09:00:00+03:00`.

## מבנה הפרויקט

```
whatsapp-connector/
  src/
    index.js            # שרת ה-MCP וכל הגדרות הכלים
    whatsapp-client.js   # עטיפה סביב Baileys: חיבור, QR, שליחה, קליטת הודעות
    store.js             # "זיכרון" מקומי של שיחות/הודעות, נשמר ב-data/store.json
    scheduler.js          # תור הודעות מתוזמנות, נשמר ב-data/scheduled.json
    login.js              # סקריפט עזר עצמאי להתחברות ראשונית מהטרמינל
    paths.js
  data/                   # לא ב-git: session, זיכרון הודעות, תור תזמונים
```

## הגבלות ידועות

- אין סנכרון היסטוריה מלא מהטלפון — הקונקטור "רואה" רק הודעות שעברו דרכו מרגע החיבור (בדומה לפתיחת חלון וואטסאפ Web חדש).
- שליחת מדיה (תמונות/קבצים/סרטונים) עדיין לא נתמכת — כרגע רק טקסט. אפשר להרחיב בקלות ב-`whatsapp-client.js` (Baileys תומך בכך out of the box) אם תרצו.
- מריץ תהליך Node.js אחד מתמשך; כדי שהודעות מתוזמנות אכן ייצאו במועד, הקונקטור צריך להיות פעיל (למשל דרך `pm2`, `systemd`, או שירות דומה אם רוצים אמינות לטווח ארוך).
